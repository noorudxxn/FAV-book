What is Bootstrap?



Bootstrap is an open-source and front end framework. This framework helps in faster web development and support developers in creating responsive web pages at a quicker pace. Bootstrap provides the basic structure of HTML and CSS with predefined classes, which help you to build functionality quickly and easily with device responsiveness. Thus, It saves plenty of time. For example, no need to start developing from scratch. It is used to build Mobile-first sites.The latest version is Bootstrap 5.

Responsive Web design:


Responsive web design is an approach to creating websites that automatically fits themselves to look good on all devices from small screens to large screens.



History

The first name of Bootstrap was Twitter Blueprint it was developed by Mark Otto and Jacob Thornton at Twitter. It got released in August 2011 on GitHub. Before the existence of Bootstrap, for making responsive sites and interface development, various external libraries were used, that not only brings inconsistency but also gave rise to the heavy maintenance burden.


Bootstrap3 vs Bootstrap4


The bootstrap new version has come up with some significant changes, adding new components, eliminate others. CSS source file used in Bootstrap 3 was LESS whereas in Bootstrap 4 was SASS. There is a lot of difference between Bootstrap 3 and 4. Now everyone is using Bootstrap 4 which is an updated one.


Bootstrap 4 is not supported in Internet Explorer 9 and down. Bootstrap 3 is supported for all browsers. If you want to use IE9 and below browsers go for Bootstrap 3.


Uses of Bootstrap


Speed Of Development : Rather than coding from scratch, Bootstrap enables you to utilize ready made blocks of code to help you get started. Combine that with cross-browser compatibility and CSS-Less functionality, many hours of coding can be saved

Responsiveness : Web pages designed using the Bootstrap framework has responsive CSS that can adjust to the screen size of large desktops, notebooks, tablets, and mobiles.

Consistency : Consistency was the fundamental principle behind the introduction of Bootstrap. It ensures the ultimate consistency regardless of designer/developer, who is working on it. Moreover, the results work uniformly across various browsers and the output remains same.

Bootstrap resolves a lot of cross-browser issues and you don't need to worry about that most of the time.

Bootstrap offers a lot of helper classes that make development of a responsive website easy and fast.
